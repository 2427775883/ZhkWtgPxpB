# Python鲜花商城源码分享

## 核心功能
- 登录注册
- 鲜花分类
- 鲜花列表
- 社区交流
- 购物车
- 下单
- 收藏
- 用户管理
- 商品管理
- 订单管理
- 分类管理
- 帖子管理

## 适用场景
- 网上鲜花销售平台
- 社区交流互动
- 用户自主管理购物流程

## 技术特点
- 采用Django框架进行后端开发
- 使用MySQL数据库存储数据
- 前端采用Vue技术实现用户界面
